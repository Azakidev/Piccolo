# Piccolo

Piccolo is a color picker built with GTK4 and Libadwaita using the components
from my other project, [Brush](https://github.com/Azakidev/Brush).

I made this in one day, 12/05/2026, because I got annoyed at gcolor3.
That said gcolor3 was a very big inspiration for the color wheel found in Brush
and in this project.

## Features
- You can pick colors!!!!!!!!!!!!!!!!!!!!!!!!!!!
- You can select a color
- You can copy colors in different formats as their CSS functions
    - Rgb
    - Rgba
    - Hsl
    - Hsv
    - OkLab
    - More to come soon
- Very neat UI
